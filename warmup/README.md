# Warm-up exercises

The four starter tasks, framed around book ids and titles. They demonstrate fundamentals and are
not part of the library domain, so they live here rather than in `Library.Service`.

| # | Task | Method |
|---|------|--------|
| 1 | Is a book id a power of two | `BookExercises.IsPowerOfTwo` |
| 2 | Reverse a book title | `BookExercises.ReverseTitle` |
| 3 | Generate book title replicas | `BookExercises.RepeatTitle` |
| 4 | List odd-numbered book ids | `BookExercises.OddBookIdsUpTo` |

## Run

```
dotnet run --project warmup/Warmup.csproj
```
